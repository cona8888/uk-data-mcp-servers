# Attribution and scope

This is an original implementation inspired by
[Koomook/data-go-mcp-servers](https://github.com/Koomook/data-go-mcp-servers)
(Apache-2.0). No source code from that repository was copied into this package.
The original project demonstrates per-provider Python MCP adapters for
Korea's data.go.kr APIs.

The MCP implementation uses the official
[Model Context Protocol Python SDK](https://github.com/modelcontextprotocol/python-sdk)
(MIT). Dependency distributions retain their own notices/licences.

The MIT licence in this repository applies to this project's code. It does
not relicense provider data, BGS reports, OS products, third-party geospatial
material, restricted utility records or any model-generated analysis. Provider
licences and attributions are recorded in `src/uk_data_mcp/sources.json` and
returned with data. Current provider terms govern use.
