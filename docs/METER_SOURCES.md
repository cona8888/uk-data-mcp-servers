# Yorkshire domestic meter data: catalogue crosswalk

The [Calderdale entry](https://www.data.gov.uk/dataset/6900f4b9-5fa9-4938-bd6b-977920d2d7f3/customer-meter-data) describes historic actual and estimated readings and states the Open Government Licence. A national directory API response for the same UUID returned metadata without file links. `dataset_record('meter_yorkshire')` first checks that record and then, only when its resource list is empty, checks the [Data Mill North catalogue entry](https://www.data.gov.uk/dataset/8e6a9811-59ea-46de-a941-4207a3641292/customer-meter-data1). The response identifies each publisher, record, licence and retrieval separately. A catalogue hash does not authenticate a linked CSV. The [Yorkshire Water publisher page](https://datamillnorth.org/dataset/customer-meter-data-2jqzm) provides year-specific downloads and attributes the deposit under Creative Commons Attribution. Use the terms of the file actually obtained. No home or meter identifiers are downloaded by MCP.

The local meter aggregation command accepts both GROSS_CONSUMPTION and the published guide's GROSS_COMSUMPTION spelling; ambiguous headers are rejected. Do not infer an actual-versus-estimated flag solely from the identity of the meter reader. Statistics are grouped by `READING_SOURCE` as published. See [Public Data](PUBLIC_DATA.md) for examples.
